# Avaliações Parciais

Aqui estarão os código de algumas "avaliações parciais" da disciplina que descobrimos da melhor forma possível (contém ironia) que seriam "avaliações supresas". Me senti na Codecon.

## Como executar

**Arquivos Java soltos** (exercícios e atividades):

```bash
cd <pasta_da_atividade>
javac NomeDoArquivo.java
java NomeDoArquivo
```

## Como testar

Com o JUnit devidamente importado e o plugin Surefire também devidamente importado:

```bash
mvn test
```

## Requisitos

- JDK 8+
